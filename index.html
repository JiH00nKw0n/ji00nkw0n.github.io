Research Interests

My research focuses on understanding and improving the internal representations of machine learning models. These representations, often called embeddings, encode information as vectors. I study what they capture and how changing them affects a model's behavior, with the goal of using that understanding to improve model performance.

Selected Publications

Same Concept, Different Directions: Cross-Modal Feature Heterogeneity in Sparse Autoencoders

Chungpa Lee*, Jihoon Kwon*, Kyle Min, Jy-yong Sohn
Conference on Neural Information Processing Systems (NeurIPS 2026)

Question: Do semantically corresponding image and text features share the same feature vector direction in the joint embedding space of CLIP-style multi-modal models?

Answer: Semantically corresponding image and text features can have different feature vector directions. The proposed method trains separate sparse autoencoders on image and text embeddings, then aligns corresponding latent coordinates using activation correlations without changing the learned feature vector directions.

Distributional Alignment as a Criterion for Designing Task Vectors in In-Context Learning

Jihoon Kwon*, Jiwon Choi*, Jy-yong Sohn
Conference on Neural Information Processing Systems (NeurIPS 2026)

Question: How can we evaluate and design task vectors that encode task-relevant information from in-context learning?

Answer: The proposed metric measures the discrepancy between next-token probability distributions over task labels under task-vector inference and in-context learning. Lower discrepancy correlates with higher classification accuracy. Guided by the proposed metric, Linear Task Vector estimates task vectors through linear regression on the difference between the last input token's final-layer hidden states with and without demonstrations.

Enhancing Compositional Reasoning in CLIP via Reconstruction and Alignment of Text Descriptions
Jihoon Kwon, Kyle Min, Jy-yong Sohn
Conference on Neural Information Processing Systems (NeurIPS 2025)

Question: How can CLIP's text encoder better capture relationships between words to improve compositional reasoning?

Answer: The proposed READ method supplements contrastive fine-tuning with reconstruction of paraphrased captions from original caption embeddings through a frozen decoder, plus alignment between original and paraphrased caption embeddings. Applying READ to CLIP yields READ-CLIP and improves compositional reasoning across five benchmarks.
